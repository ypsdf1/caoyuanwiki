## 指令介绍
| 指令 | 参数1 | 参数2 | 参数3 |  结果|
| :---: | :---: | :---: | :---: | :---: |
| quiz | 无 | 无 | 无 |  帮助 |  
| quiz | start | 无 | 无| 出题 | 
| quiz | info | 无 | 无 | 状态 |
| quiz | reload | 无 | 无| 重载 | 
| quiz | start | 题型 | 题目内容/编号(从上到下第N题) |  出指定的题目 |


## 配置文件：
```text
# ===== 快问快答 主配置 =====
# 支持 # // /* */ <!-- --> 注释

# 运行模式: 自动 / 手动
# 模式区别：手动模式：纯手动出题，自动模式是手自一体化
模式: 自动

# 最少在线人数
最少在线人数: 3

# 出题间隔
# 支持: 秒(s) 分钟(m) 小时(h)
最小间隔: 5分钟
最大间隔: 15分钟

# 答题时间
答题时间: 2分钟

# 蒙题防护
# 选择题中，2秒内错误答案超过此数则罚时
# 罚时期间答案无效
蒙题检测数: 2

# 罚时时间（秒）
# 支持: 秒(s) 分钟(m) 小时(h)
罚时时间: 10秒

# 消息前缀
消息前缀: §e§l【快问快答】§r

# 蒙题防护提示
罚时开始提示: §c你回答太快了，请冷静10秒！
罚时结束提示: §a罚时已结束，你可以继续答题了


```

- 填空题<br>
- 问答题
