- [Sdf1_login](sdf1_login.md) 用途：经济提供者

## 指令介绍
| 指令 | 参数1 | 参数2 | 参数3 |  结果|
| :---: | :---: | :---: | :---: | :---: |
| quiz | 无 | 无 | 无 |  帮助 |  
| quiz | start | 无 | 无| 出题 | 
| quiz | info | 无 | 无 | 状态 |
| quiz | reload | 无 | 无| 重载 | 
| quiz | start | 题型 | 题目内容/编号(从上到下第N题)/随机 |  出指定的题目/出指定题型的随机题目 |
| 出题 | 无 | 无 | 无 | 随机出题 |
| quiz | start | 无 | 无 | 随机出题 |



## 配置文件：
```text
# ===== 快问快答 主配置 =====
# 支持 # // /* */ <!-- --> 注释

# 运行模式: 自动 / 手动
# 模式区别：手动模式：纯手动出题，自动模式是手自一体化
模式: 自动

# 最少在线人数
最少在线人数: 3

# 出题间隔
# 支持: 秒(s) 分钟(m) 小时(h)
最小间隔: 5分钟
最大间隔: 15分钟

# 答题时间
答题时间: 2分钟

# 蒙题防护
# 选择题中，2秒内错误答案超过此数则罚时
# 罚时期间答案无效
蒙题检测数: 2

# 罚时时间（秒）
# 支持: 秒(s) 分钟(m) 小时(h)
罚时时间: 10秒

# 消息前缀
消息前缀: §e§l【快问快答】§r

# 蒙题防护提示
罚时开始提示: §c你回答太快了，请冷静10秒！
罚时结束提示: §a罚时已结束，你可以继续答题了


```
## 题目支持：
- 选择题<br>
- 填空题<br>
- 问答题

## 寻宝玩法介绍

| 指令 | 参数1 | 参数2 | 参数3 |  结果|
| :---: | :---: | :---: | :---: | :---: |
| 寻宝 | 无 | 无 | 无 | 帮助 |
| 寻宝 | 工具 | 无 | 无 |  获取圈地工具 |
| 寻宝 | 名字 | 无 | 无 | 创建宝藏埋藏点 |
| 寻宝| on | 名字 | 无 | 展示宝藏区域边框 |
| 寻宝 | off | 名字 | 无 | 远比宝藏区域板块 |
| 寻宝 | reload | 无 | 无 | 重载插件 |
| 寻宝 | removeregion | 名字 | 无 | 删除宝藏地点 |
| 寻宝 | expand | 名字 | 可填数字 | 扩张宝藏埋藏范围 |
| 寻宝 | return | 名字 | 可填数字 | 缩小宝藏埋藏范围 |
